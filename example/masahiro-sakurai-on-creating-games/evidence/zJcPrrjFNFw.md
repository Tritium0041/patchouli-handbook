## Summary
这个视频讲述了“Press Start”游戏音乐管弦乐音乐会系列的起源、发展历程和幕后故事。该音乐会由植松伸夫、竹本泰造、堺翔吾、野岛一成等人于2006年创办，持续了10年，每年一次，演出曲目涵盖多个游戏系列。视频还讨论了游戏音乐管弦乐化的挑战、音乐会的制作流程以及疫情对现场演出的影响。

## Key Points
- Press Start 是2006年至2016年每年举办一次的游戏音乐管弦乐音乐会。
- 发起人包括植松伸夫、竹本泰造、堺翔吾、野岛一成等，起因于2002年FF和Smash Bros. Deluxe音乐会的机缘。
- 音乐会曲目由主讲人（自称唯一游戏通）筛选，通常14-16个曲目，但包含约60首乐曲的混合。
- 制作流程包括选曲、编曲、排练和正式演出，避免过多视觉干扰。
- 音乐会曾面临持续举办的困难，但最终完成了10年的目标。
- 之后日本游戏音乐音乐会增多，Press Start 认为已完成历史使命。
- 新冠疫情对现场演出造成冲击，希望未来演出能恢复。
