# Smash Bros. DOJO!!

Category: Marketing & Communication

## Summary
The Smash Bros. DOJO website started as a manual to explain the game's unique appeal, later evolved into official daily-updated news site. Key: consistent, developer-driven updates.

## Use When
- Planning game's promotional campaign or community site.

## Do This
1. Start updates early; commit to schedule (daily); involve developers for authentic voice; consider multiple languages.

## Checklist
- Establish content update schedule
- Create central hub for news and features
- Include developer commentary
- Localize for key markets
- Use updates to clarify unique mechanics

## Anti-Patterns
- Inconsistent updates
- Generic corporate messaging
- Ignoring community questions
