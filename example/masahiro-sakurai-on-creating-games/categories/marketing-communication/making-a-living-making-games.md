# Making a Living Making Games

Category: Marketing & Communication

## Summary
The most direct path into the game industry is to make your own games, starting with clones and iterating based on feedback.

## Use When
- You want to enter the industry without portfolio.

## Do This
1. Choose engine, learn basics, clone a simple game and complete, get playtest feedback, add original elements, submit with resume.

## Checklist
- Learned a game development tool
- Completed at least one full clone
- Gotten feedback from testers
- Added original elements
- Submitted application with portfolio

## Anti-Patterns
- Waiting for job opening before making anything
- Afraid of copying initially
- Ignoring programming because want to be designer
