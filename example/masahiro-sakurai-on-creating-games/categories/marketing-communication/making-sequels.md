# Making Sequels

Category: Marketing & Communication

## Summary
Sequels can leverage existing systems but must deliver noticeable improvement over the original to overcome likely sales drop (often 50%).

## Use When
- Planning a sequel or franchise entry.

## Do This
1. Ensure core gameplay refined, new content substantial, sequel feels distinctly better; monitor player feedback.

## Checklist
- Identify improvements over predecessor
- Add meaningful new features or content
- Avoid feature creep but maintain polish
- Communicate enhancements clearly

## Anti-Patterns
- Minimal changes feeling like expansion pack
- Ignoring what made original successful
