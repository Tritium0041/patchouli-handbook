# Official Websites

Category: Marketing & Communication

## Summary
Websites remain vital for deep, centralized information; earlier used to correct bias (e.g., Smash Bros.).

## Use When
- Establishing game's online presence or combating misinformation.

## Do This
1. Structure content with depth (characters, modes, techniques). Use to show game's real value.

## Checklist
- Decide if full site needed vs. social media
- Plan architecture mirroring game complexity
- Include tutorials, system explanations, media
- Update regularly

## Anti-Patterns
- Relying solely on social media for detailed info
- Using generic templates without game-specific design
