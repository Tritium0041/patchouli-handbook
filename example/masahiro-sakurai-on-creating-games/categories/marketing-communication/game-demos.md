# Making and Releasing Game Demos

Category: Marketing & Communication

## Summary
Demos are effective marketing but costly: require separate builds, version management, risk spoiler leaks. Evaluate resources.

## Use When
- Deciding whether to create a demo.

## Do This
1. Allocate dev time for demo polish. Remove all spoiler content. Set up separate branch. Test thoroughly. Consider post-launch demo.

## Checklist
- Demo build stripped of future content
- Separate version control
- Demo tested on all platforms
- Clear communication on contents

## Anti-Patterns
- Rushing demo without QA
- Including unannounced features
- Neglecting demo updates
- Expecting demo to represent final perfectly
