# Crafting Games Similar to Existing Ones

Category: Marketing & Communication

## Summary
It's common to make games inspired by existing titles, but you must offer unique appeal that the original doesn't have.

## Use When
- Developing a game that intentionally resembles a known franchise.

## Do This
1. Analyze what the original lacks; add your own unique mechanics, story, or theme; combine several original strengths to differentiate.

## Checklist
- Identify core fun of original
- List at least three missing features you can add
- Ensure game has distinct identity
- Don't worry surpassing; focus on differences

## Anti-Patterns
- Cloning without adding value
- Relying solely on nostalgia
