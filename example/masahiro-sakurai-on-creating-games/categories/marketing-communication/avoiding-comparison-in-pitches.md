# Avoiding Comparison in Pitches

Category: Marketing & Communication

## Summary
When presenting a new game idea, avoid describing it as 'like [existing game]'. Focus on unique value proposition.

## Use When
- Pitching a new game concept.

## Do This
1. Describe game in its own terms; highlight novel mechanics; let audience draw own parallels.

## Checklist
- Identify core unique selling points
- Avoid 'like X' in presentations
- Prepare to explain differences if compared

## Anti-Patterns
- Using famous game as shorthand
- Relying on clone comparisons
- Assuming everyone knows reference
