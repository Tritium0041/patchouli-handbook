# Ensure Product Image Matches Reality

Category: Marketing & Communication

## Summary
Never mislead consumers; trailers and screenshots must accurately represent the final game.

## Use When
- Creating marketing assets.

## Do This
1. Use actual gameplay footage or closely represent final product. Avoid cinematic that exaggerates features not present.

## Checklist
- Review all promotional materials for accuracy
- Avoid using target renders as final
- Disclose if footage from development build
- Update materials if game changes

## Anti-Patterns
- Fake gameplay or bullshots
- Promising features not in game
- Misleading comparisons
