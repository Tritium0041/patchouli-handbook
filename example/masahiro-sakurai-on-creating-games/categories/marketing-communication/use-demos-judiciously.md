# Use Demos Judiciously

Category: Marketing & Communication

## Summary
Demos can be effective but require significant effort and may spoil experience if not well-crafted.

## Use When
- Considering a public demo release.

## Do This
1. Weigh benefits (buzz, feedback) against costs (development time, version management). If making, ensure polished and representative.

## Checklist
- Decide demo purpose (hype vs. feedback)
- Allocate resources for demo development separately
- Keep demo self-contained and updated
- Plan for demo feedback integration

## Anti-Patterns
- Rushed, buggy demos hurting reputation
- Demo spoiling full game surprises
- Maintaining multiple versions with no plan
