# Sound Feedback

Category: Marketing & Communication

## Summary
When giving sound effect feedback, be specific: 'more attack', 'higher pitch'. Reference known sounds. Vague onomatopoeia like 'gaki' doesn't help.

## Use When
- Reviewing sound effects from audio team.

## Do This
1. Describe the feeling you want. Provide examples. Accept sounds that serve purpose even if differ from initial imagination.

## Checklist
- Provided concrete reference or description?
- Avoiding onomatopoeia only you understand?
- Considered context (gunshot in cave vs. open)?

## Anti-Patterns
- Saying 'make it cooler' without specifics
- Rejecting sound just because not what pictured
- Using lengthy emails with no reference
