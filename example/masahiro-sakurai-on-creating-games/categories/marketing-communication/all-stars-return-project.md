# All Stars Return Project

Category: Marketing & Communication

## Summary
Super Smash Bros. Ultimate's core concept: bring back every previous character. Clear vision and managing constraints.

## Use When
- Planning large-scale crossover or sequel with high expectations.

## Do This
1. Set clear, ambitious goal; anticipate technical bottlenecks; engage community; plan for post-launch content.

## Checklist
- List essential content to include
- Assess memory/performance limits
- Secure necessary licenses
- Prepare contingency for remote work

## Anti-Patterns
- Scope creep without clear vision
- Underestimating content volume
- Ignoring engine limitations
