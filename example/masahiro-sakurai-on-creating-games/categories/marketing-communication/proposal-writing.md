# Proposal Writing

Category: Marketing & Communication

## Summary
Write proposals with one idea per page. Use one image and max two lines of text. Many pages fine as long as each clear.

## Use When
- Creating design docs, pitch decks, or feature specs.

## Do This
1. Start with rough outline, fill page by page. Keep text minimal. Use screenshots, mockups, diagrams. Print and review layout.

## Checklist
- Each page understood in 5 seconds?
- Consistent visual style?
- Cut unnecessary text?

## Anti-Patterns
- Dense paragraphs
- Mixing multiple concepts on one page
- Perfecting layout before writing content
