# Writing Game Proposals

Category: Marketing & Communication

## Summary
Proposal style: each slide has one image and one sentence; can be long (200+ pages) but easy to flip through like a comic. Include categories and progress indicators.

## Use When
- Creating design document or pitching.

## Do This
1. Keep slides simple: one visual, one line of text. Organize into categories with progress bars. Present without reading text directly.

## Checklist
- One image per slide with minimal text
- Provide category and subcategory structure
- Include progress indicator
- Practice presenting without reading

## Anti-Patterns
- Dense text slides
- No structure or endpoint feeling
- Reading slides aloud
