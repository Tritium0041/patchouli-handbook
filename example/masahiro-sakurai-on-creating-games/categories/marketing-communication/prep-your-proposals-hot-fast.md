# Prep Your Proposals Hot and Fast

Category: Marketing & Communication

## Summary
Game proposals should be written quickly and concisely while enthusiasm is high. Focus on fun, not lengthy explanations.

## Use When
- Writing a game proposal or pitch.

## Do This
1. Plan main and sub-sections before writing. Keep text brief, use visuals. Write in one go while passion fresh. If rejected, improve communication.

## Checklist
- Is proposal concise?
- Does it emphasize fun over features?
- Are there visuals?
- Written while excited?
- If rejected, analyzed pitch?

## Anti-Patterns
- Overloading with data or alternatives
- Complaining about rejecters
