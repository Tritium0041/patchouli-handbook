# Debug Mode

Category: Development Insights

## Summary
Implement a debug mode early with features like invincibility, camera control, stat adjustment. Use a single controller for all debug functions.

## Use When
- During development to test mechanics and find bugs.

## Do This
1. Program a toggleable debug mode. Include functions to change HP, damage, speed. Keep UI clean.

## Checklist
- Can manipulate core parameters with one controller?
- Debug mode easily toggled?
- Debug tools consolidated to avoid searching for multiple controllers?

## Anti-Patterns
- Debug mode clutters screen with too many numbers
- Using second controller for debug
- Leaving debug mode enabled in final build
