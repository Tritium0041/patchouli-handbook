# Frame Rates

Category: Development Insights

## Summary
Frame rate is the basic unit of game time, usually 60fps standard. 30fps common but 60fps smoother. NTSC/PAL differences affect speed; variable frame rate can maintain consistency.

## Use When
- Deciding target frame rate or handling cross-region versions.

## Do This
1. Prefer 60fps but adjust to platform. Note NTSC/PAL differences. Test different frame rates on action games.

## Checklist
- Confirm target frame rate early
- Test both 60fps and 30fps on target hardware
- Check regional speed consistency
- Consider variable or fixed rate

## Anti-Patterns
- Blindly pursuing high fps ignoring performance
- Ignoring regional differences
- Unstable frame rate without compensation
