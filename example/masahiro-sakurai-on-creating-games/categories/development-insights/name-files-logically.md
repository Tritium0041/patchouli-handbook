# Name Files Logically

Category: Development Insights

## Summary
Use consistent naming conventions: 'Attack' for normal moves, 'Special' for specials, direction codes (N, S, L), strength numbers. Use English.

## Use When
- Setting up file structure for project with many assets.

## Do This
1. Define prefix per category, directional suffixes, numbers for strength. Use English terms.

## Checklist
- Established naming convention
- Used English not romanized Japanese
- Ensured consistency across team

## Anti-Patterns
- Romanized Japanese for international team
- Too short cryptic names
- Inconsistent formatting
