# Staying Organized with Hierarchical Outlines

Category: Development Insights

## Summary
Use outline view to structure ideas hierarchically, ideal for personal planning.

## Use When
- Brainstorming or writing design docs.

## Do This
1. Create nested text levels; collapse/expand to focus; keep for personal use.

## Checklist
- Open Outline view in Word
- Use headings for main categories, subheadings for details
- Fold deeper levels to see big picture
- Export clean doc for public presentation

## Anti-Patterns
- Using raw outline for external communication without editing
- Over-nesting
