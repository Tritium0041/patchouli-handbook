# Put Parameters in Brackets

Category: Development Insights

## Summary
Distinguish between program logic and adjustable parameters. Use brackets in specs to denote parameter names and circles to mark values needing tuning. Store in separate files.

## Use When
- Writing game specs or implementing data-driven systems.

## Do This
1. Enclose parameter names in square brackets in docs, circle values. Programmers read from external files. Name intuitively.

## Checklist
- List all tunable values
- Wrap parameter names in brackets
- Circle default values in spec
- Implement parameter file format (JSON, spreadsheet)
- Document naming conventions

## Anti-Patterns
- Hard-coding values in scripts
- Vague parameter names like 'speed1'
