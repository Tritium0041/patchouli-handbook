# Mushi King Development

Category: Development Insights

## Summary
A small-team LSI game featuring beetle raising and battling. Balance growth phases, hidden specs add depth, watch for platform speed differences.

## Use When
- Designing small-scale game with limited resources.

## Do This
1. Ensure raising phase has peaks and valleys. Add hidden quirks for replayability. Verify performance on target hardware.

## Checklist
- Design raising cycle: alternating strong and weak phases
- Include hidden behaviors
- Test gameplay speed on actual device
- Keep team communication clear
- Balance competitive aspects

## Anti-Patterns
- Uniform growth curve
- High hunger speed causing stress (hardware mismatch)
- Overcomplicated mechanics
