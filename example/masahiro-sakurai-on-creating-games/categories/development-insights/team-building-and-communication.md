# Team Building and Communication

Category: Development Insights

## Summary
Sakurai shares how he assembled the Smash Bros X team from external companies. Good communication and respect are key.

## Use When
- Forming a cross-company team.

## Do This
1. Create shared space. Establish clear communication channels. Respect each partner's expertise and culture.

## Checklist
- Select partners whose strengths complement weaknesses
- Hold regular sync meetings
- Promote culture of mutual respect
- Provide necessary tools and environment

## Anti-Patterns
- Assuming all teams work same way
- Over-communicating to distraction
- Neglecting team morale
