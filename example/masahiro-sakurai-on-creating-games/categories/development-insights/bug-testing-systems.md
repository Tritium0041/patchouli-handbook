# Bug Testing Systems

Category: Development Insights

## Summary
Establish structured bug tracking: unified ROMs, severity ranking (S/A/B/C), assignment to specialists, regression testing. Use automated testing for large games.

## Use When
- Managing QA for any game project.

## Do This
1. Start with unified build. Create detailed checklists. When bug found, file ticket with reproduction steps. Rank severity. Assign to appropriate discipline. Verify fix. Keep tickets for regression.

## Checklist
- Unified build version for all testers
- Reproduction steps documented
- Severity ranking applied consistently
- Bugs assigned to correct role
- Verification before closing
- Automated tests for large areas

## Anti-Patterns
- Different testers using different builds
- No reproduction steps
- All bugs same priority
- Closing tickets without verification
