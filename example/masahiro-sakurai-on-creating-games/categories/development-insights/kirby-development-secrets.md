# Kirby Development Secrets

Category: Development Insights

## Summary
How original Kirby was made with extreme ROM constraints: mirrored sprites, no terrain collision for enemies, prototype designs already matching final.

## Use When
- Learning creative solutions to hardware limitations.

## Do This
1. Reuse assets via symmetry, pre-program enemy paths, prototype key abilities early.

## Checklist
- Exploit sprite mirroring to halve frames
- Plan enemy movement without collision
- Draft designs on paper before tools ready
- Test early prototypes against final vision
- Embrace mysterious elements

## Anti-Patterns
- Over-reliance on complex collision for simple enemies
- Ignoring 'happy accidents'
