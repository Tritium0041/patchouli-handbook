# Naming Conventions

Category: Development Insights

## Summary
Use consistent, English-friendly naming to avoid confusion between development terms and player-facing names.

## Use When
- Starting a new project or establishing coding standards.

## Do This
1. Adopt naming rule: attack skills start with 'attack_', specials with 'special_', directions use N/S/E/W. Avoid romanized Japanese if team international.

## Checklist
- Define prefixes for skill types
- Agree on direction notation
- Document conventions in shared wiki

## Anti-Patterns
- Letting each programmer name arbitrarily
- Mixing languages in identifiers
