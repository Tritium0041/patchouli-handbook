# Making Your Game Easy to Tune

Category: Development Insights

## Summary
Parameter externalization: store all tunable numbers in Excel, use formulas for relationships, hide seldom-changed values, automate conversion.

## Use When
- Setting up data-driven tuning pipeline.

## Do This
1. Design external parameter system; organize in spreadsheets; create one-click conversion tool; hide low-frequency parameters.

## Checklist
- Separate all tunable values from code
- Use Excel for centralized management
- Leverage formulas for relative values
- Develop conversion/import tool
- Hide rarely changed parameters

## Anti-Patterns
- Hardcoding values in source code
- No relationship between related parameters
- Long conversion time
- Exposing every parameter to everyone
