# Learn to Count Frames!

Category: Development Insights

## Summary
Understanding frame length is crucial for timing game actions. With 60fps, counting '1 and 2 and 3' approximates 30 frames.

## Use When
- Designing precise timing for animations, moves, or mechanics.

## Do This
1. Insert 'and' between numbers when counting seconds to approximate 30 frames. Use known benchmarks to estimate other durations.

## Checklist
- Practice counting frames aloud with 'and' method
- Estimate 15 frames as half of 30
- Use physical reference points to calibrate
- Apply to speed, distance, action durations

## Anti-Patterns
- Assuming all frame lengths intuitive without practice
- Ignoring frame values in design specs
