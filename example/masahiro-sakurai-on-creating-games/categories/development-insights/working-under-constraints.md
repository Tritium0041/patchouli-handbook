# Creative Solutions Under Hardware Constraints

Category: Development Insights

## Summary
Tight memory and processing limits force elegant design. Example: Kirby's 512KB used symmetric graphics and pre-programmed enemy paths.

## Use When
- Developing for limited hardware or optimizing performance.

## Do This
1. Analyze constraints early. Reuse assets cleverly. Simplify to essentials. Prioritize core experience.

## Checklist
- List resource limits
- Asset reuse plan
- Use optimization tricks
- Cut features that don't add enough value

## Anti-Patterns
- Ignoring constraints until late
- Bloated code
- Over-reliance on brute force
