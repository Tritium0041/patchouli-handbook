# Ticket System

Category: Development Insights

## Summary
Use a ticket system to manage all tasks so that every job has an owner and status, preventing tasks from falling through the cracks.

## Use When
- Managing a team of any size.

## Do This
1. Issue ticket for each distinct work. Use statuses like 'in progress', 'done', 'hold'. Review regularly to catch delays.

## Checklist
- Choose a ticketing tool
- Define ticket fields: summary, assignee, status, due date
- Require every task ticketed before work begins
- Hold daily standup to update statuses

## Anti-Patterns
- Using verbal or email instructions without trail
- Ignoring tickets until last minute
