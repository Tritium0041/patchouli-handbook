# Units of Speed

Category: Development Insights

## Summary
Speed in games is defined by distance/time units. In 2D pixel games, dots/frame; in 3D, real-world units like km/h but scaled with character size.

## Use When
- Defining movement systems and speed parameters.

## Do This
1. Define game's distance unit (pixel, meter); set time unit (frames, seconds); adjust display speed based on character scale.

## Checklist
- Choose consistent units
- Scale speed with character size
- Test perceived speed

## Anti-Patterns
- Mixing units
- Ignoring character scale impact
