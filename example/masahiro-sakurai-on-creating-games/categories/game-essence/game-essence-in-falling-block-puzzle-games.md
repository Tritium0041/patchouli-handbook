# Game Essence in Falling-Block Puzzle Games

Category: Game Essence

## Summary
The key difference between pure puzzles and falling-block games is risk vs return. Time pressure and speed create tension.

## Use When
- Designing puzzle or falling-block games.

## Do This
1. Incorporate time pressure, speed changes, or scarcity to create risk. Ensure clear rewards for clearing lines.

## Checklist
- Identify risk sources
- Provide clear rewards
- Test with varying speeds

## Anti-Patterns
- Designing puzzles without risk elements
- Making the game too easy or too hard without dynamic difficulty
