# Squeeze and Release

Category: Game Essence

## Summary
Game fun originates from applying pressure (enemies, puzzles) and then releasing it with rewards. Design a clear pressure-release cycle.

## Use When
- Designing game loops and challenge systems.

## Do This
1. Introduce stressors (enemies, timers) and design satisfying release (defeating, escaping). Ensure release feels impactful.

## Checklist
- Define pressure sources
- Design clear release actions
- Balance intensity to avoid overwhelming
- Pair release with tangible rewards

## Anti-Patterns
- Constant pressure without relief
- Too much downtime without pressure
- Unclear or unsatisfying release
