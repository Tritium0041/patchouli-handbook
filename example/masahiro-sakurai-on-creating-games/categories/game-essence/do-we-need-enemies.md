# Do We Really Need Enemies?

Category: Game Essence

## Summary
The core of game satisfaction is the pressure-release cycle. Enemies are a common pressure source, but you can use other mechanisms like puzzles, time limits, or resource management.

## Use When
- Designing conflict or progression systems.

## Do This
1. For every system, ask: what is the pressure? How does the player relieve it? If no enemies, use alternatives.

## Checklist
- Identify pressure sources
- Design clear relief
- Ensure relief leads to growth
- Test satisfaction

## Anti-Patterns
- Adding enemies just because
- Creating pressure without release
