# Game Essence in RPGs

Category: Game Essence

## Summary
RPGs balance risk and reward through dangerous areas, resource management, and weakness systems.

## Use When
- Designing RPG exploration or combat.

## Do This
1. Create high-risk, high-reward zones. Implement weakness systems that add strategy without complexity. Manage resources to create tension.

## Checklist
- Include dangerous areas that tempt players
- Weakness system adds meaningful choices
- Resource management creates pressure

## Anti-Patterns
- Overcomplicating weakness systems
- Making safe areas completely risk-free
