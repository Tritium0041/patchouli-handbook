# That Was Then, This Is Now

Category: Player Experience

## Summary
Each era has merits; modern games are more polished but older ones often innovated more. Encourage trying new games.

## Use When
- Evaluating game design trends or overcoming personal bias.

## Do This
1. Play modern games with open mind; appreciate each era's context; avoid dismissing new games due to nostalgia.

## Checklist
- Periodically try games from different eras
- Acknowledge fun is relative to context
- Don't let nostalgia prevent enjoyment

## Anti-Patterns
- Claiming 'old games are better' without trying new ones
- Only playing remakes or classics
