# Praise the Player

Category: Player Experience

## Summary
Celebrate player actions with visual, audio, or text praises—even for minor achievements—to boost motivation.

## Use When
- Designing moment-to-moment feedback.

## Do This
1. Add confetti, sound effects, teammate compliments, or score bonuses for successful actions. Also praise near-misses.

## Checklist
- Identify key actions deserving celebration
- Design unique feedback for each
- Include praise for errors too
- Use dynamic scaling
- Test that praise matches emotional state

## Anti-Patterns
- No feedback for clear achievements
- Generic praise
- Over-praising trivial actions
