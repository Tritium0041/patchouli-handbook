# Just Let Them Play

Category: Player Experience

## Summary
Game should show core fun within first 3 minutes; avoid lengthy prologues; let players play immediately.

## Use When
- Designing game opening or trailer.

## Do This
1. Quickly enter playable content; integrate tutorial into gameplay; use flashforward to show core mechanics early.

## Checklist
- First 3 minutes show core fun?
- Trailer opens with actual gameplay?
- Tutorial natural?

## Anti-Patterns
- Long story demo at start
- Separate mandatory tutorial mode
