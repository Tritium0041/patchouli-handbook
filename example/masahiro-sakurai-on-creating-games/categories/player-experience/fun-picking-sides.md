# The Fun in Picking Sides

Category: Player Experience

## Summary
Choosing a side increases engagement in competitive games. Use prediction mechanics for emotional investment.

## Use When
- Designing spectator modes or betting systems.

## Do This
1. Add lightweight prediction or betting mechanics (non-monetary) to increase viewer engagement.

## Checklist
- Identify where players need to take sides
- Implement low-risk, low-reward hook
- Ensure no gambling issues
- Test for emotional response

## Anti-Patterns
- Adding betting that feels like gambling
- Forcing support that player has no connection to
