# Game Opening

Category: Player Experience

## Summary
Your game must hook players within the first 3 minutes. Skip lengthy intros; jump into core gameplay immediately.

## Use When
- Designing tutorial, first level, or demo.

## Do This
1. Start with small, achievable challenge showcasing best mechanic. Use contextual tutorials. Add optional lore later.

## Checklist
- Timed test: does player experience core loop within 3 minutes?
- Remove any non-interactive opening delaying gameplay
- Ensure first action is satisfying

## Anti-Patterns
- Long cinematic before gameplay
- Overwhelming tutorial text before player can move
- Starting with boring task
