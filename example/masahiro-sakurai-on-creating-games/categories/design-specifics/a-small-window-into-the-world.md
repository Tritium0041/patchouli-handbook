# A Small Window Into the World

Category: Design Specifics

## Summary
Screen view is only ~30° field of view; affects racing games especially. VR helps for direction-independent games. Design UI considering actual screen usage area.

## Use When
- Designing games for standard screens or VR.

## Do This
1. Account for limited FOV in gameplay; consider VR for racing; place important UI where players naturally look.

## Checklist
- Recognize screen FOV limitation (~30°)
- For racing, consider VR for immersion
- Layout UI based on typical gaze areas (center, lower third)

## Anti-Patterns
- Assuming full peripheral vision
- Placing critical info at screen edges
