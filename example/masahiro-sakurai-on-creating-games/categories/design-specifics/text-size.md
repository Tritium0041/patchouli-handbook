# Text Size

Category: Design Specifics

## Summary
Ensure text large enough for different languages, especially Japanese; consider adjustable text size options.

## Use When
- Designing UI supporting multiple languages.

## Do This
1. Test UI with largest typical text (e.g., Japanese). Provide text size slider. Prioritize readability over aesthetics.

## Checklist
- Checked text size for all target languages
- Added text size option
- Tested on small screens

## Anti-Patterns
- Designing UI only for English
- Using pixel fonts too small on high-res screens
- Prioritizing aesthetic over readability
