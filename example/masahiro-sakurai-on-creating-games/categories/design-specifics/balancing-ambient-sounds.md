# Balancing Ambient Sounds

Category: Design Specifics

## Summary
Ambient sounds have low priority but are essential for immersion. Present during quiet moments, never overpower key effects.

## Use When
- Designing audio for any scene that should feel alive.

## Do This
1. Set ambient volume carefully; use real recordings; apply reverb; keep sounds running during exploration.

## Checklist
- Test that ambient doesn't mask important sounds
- Use high-quality speakers/headphones
- Reference film sound design
- Ensure sounds match environment

## Anti-Patterns
- Complete silence during pauses
- Ambient too repetitive or distracting
- Synthetic sounds breaking immersion
