# Customization Lets Your Imagination Play

Category: Design Specifics

## Summary
Five key points: visualize effects, clear pros/cons, easy selection, quick testing, cool design. Customization itself must be fun.

## Use When
- Designing equipment, skill, or character customization.

## Do This
1. Show effect changes visually rather than just numbers. Make each option have clear advantages and disadvantages. Provide filters and auto-equip. Allow immediate testing. Ensure items look cool.

## Checklist
- Visual feedback for each option
- Each option has clear pros and cons
- Filter/sort UI for easy browsing
- Quick test mode available
- Designs aesthetically pleasing

## Anti-Patterns
- Only stat changes without visual representation
- Too many similar options without meaningful differences
- Forcing exit to test
- Neglecting visual design
