# Blade Trails

Category: Design Specifics

## Summary
Two main methods: polygon trails (for most swings) and billboard placement (for fast, single-frame swings). Customize trail per character.

## Use When
- Creating weapon trails in 3D games.

## Do This
1. Use polygon trails for normal swings; billboard for fast swings combined with hitstop. Design unique trail appearance per character.

## Checklist
- Trail method chosen based on swing speed
- Polygon trail adjusted to avoid shell-like appearance
- Billboard trails with proper hitstop timing
- Character-specific design applied

## Anti-Patterns
- Polygon trails for fast swings where billboard better
- Not adjusting animation for side visibility
- Generic trails not matching character
