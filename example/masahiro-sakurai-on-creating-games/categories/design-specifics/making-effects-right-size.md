# Making Effects the Right Size

Category: Design Specifics

## Summary
Effects must be scaled correctly relative to characters. Common mistake: making flames too large, looking like candle flames.

## Use When
- Creating particle effects, especially fire or energy.

## Do This
1. Compare effect size to character proportions; use reference images; keep motion rough and fast rather than overly detailed.

## Checklist
- Check scale against character and environment
- Use looping textures or particle boards to control size
- Prioritize speed and roughness over precision
- Test from multiple camera angles

## Anti-Patterns
- Effects huge but lacking mass (candle flame look)
- Overly slow and detailed flames losing impact
- Ignoring scale consistency
