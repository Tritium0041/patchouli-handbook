# Making Work Games Fun

Category: Design Specifics

## Summary
Games lacking traditional risk-reward can still be fun through realistic tasks, clear reward loops, and satisfying progression.

## Use When
- Designing simulation or idle games.

## Do This
1. Provide visible progress and rewards; pick familiar real-world activities; design upgrade chain; allow endless play or far-off goal.

## Checklist
- Choose relatable real-world activity
- Implement clear reward system
- Make repetitive actions satisfying
- Consider adding unexpected elements

## Anti-Patterns
- No sense of progress or closure
- Too many tutorials ruining flow
- Rewards meaningless or too slow
