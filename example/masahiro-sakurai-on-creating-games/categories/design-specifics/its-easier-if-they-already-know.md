# It's Easier If They Already Know

Category: Design Specifics

## Summary
Leverage industry-standard controls to reduce learning curve; always allow full button remapping.

## Use When
- Defining control schemes or creating tutorials.

## Do This
1. Adopt common control layouts for your genre. Skip explanation of standard actions; just highlight button. Provide full remapping.

## Checklist
- Default controls match genre conventions
- Tutorial acknowledges prior knowledge
- Full remapping available
- Limitations documented

## Anti-Patterns
- Forcing lengthy controller diagrams
- Removing remapping because 'we know best'
- Mapping core action to unconventional button without option
