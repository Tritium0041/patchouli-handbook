# Handicap Systems

Category: Design Specifics

## Summary
Handicaps balance skill gaps in multiplayer. In Smash Bros., intentional manual handicapping is most effective.

## Use When
- Creating local multiplayer or competitive games.

## Do This
1. Offer random elements that naturally help weaker players; allow manual adjustments; consider auto-handicap.

## Checklist
- Include items or abilities benefiting trailing players
- Provide auto-handicap toggle
- Encourage manual handicapping (e.g., giving Smash Balls)

## Anti-Patterns
- Handicap too obvious ruining fair play sense
- No handicap option
- Auto-handicap that feels unfair to skilled players
