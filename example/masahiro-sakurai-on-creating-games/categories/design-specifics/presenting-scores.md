# Presenting Scores in Meaningful Ways

Category: Design Specifics

## Summary
Raw scores less engaging. Attach to relatable concepts (brain age, total damage) transforms perception. Quick counting feedback enhances satisfaction.

## Use When
- Implementing any scoring or numerical reward system.

## Do This
1. Find context-dependent scale (e.g., age, currency, rank); add rapid tally animations; link to player progress.

## Checklist
- Identify meaningful real-world analog for score
- Animate score increments (fast ascending numbers)
- Provide sense of achievement
- Consider loss totals for challenge modes

## Anti-Patterns
- Score displayed as just number with no context
- Slow or choppy counting animations
- Score feeling arbitrary
