# Giving Weight to Buttons

Category: Design Specifics

## Summary
Button feel is determined by in-game action parameters (speed, frame rate). Design considering tactile feeling.

## Use When
- Setting character movement, jump, or attack parameters.

## Do This
1. Test different parameters for perceived weight; adjust input thresholds for different controllers.

## Checklist
- Does movement speed affect button feel?
- Animation frame rate matches expected weight?
- Different controllers need separate calibration?

## Anti-Patterns
- Ignoring feel, only focusing on numeric balance
- Same input settings on all platforms
