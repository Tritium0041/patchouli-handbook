# The Potential of One Button

Category: Design Specifics

## Summary
Single-button games can be categorized into four types: rapid fire, timing, speed press, and toggle. Match operation feel to game sense.

## Use When
- Designing micro-games or minimal-input experiences.

## Do This
1. Identify which button type fits your desired gameplay. Ensure feedback matches input. Test for fatigue and comfort.

## Checklist
- Button action clearly communicated?
- Feedback matches input type?
- Comfortable for extended play?
- Considered combining two types?

## Anti-Patterns
- Overloading single button with multiple ambiguous actions
