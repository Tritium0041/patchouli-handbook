# Hit Marks: Designing Impact Effects

Category: Design Specifics

## Summary
Hit marks must be flashy, clear contrast, appear at exact hit point, combine multiple effects, avoid obscuring characters, adjust duration based on game pace.

## Use When
- Creating combat hit effects.

## Do This
1. Ensure each hit mark has visual flair. Combine multiple particle layers. Position precisely at collision. Test against varied backgrounds. During hitstop, keep effects dynamic.

## Checklist
- Effect clearly visible against common backgrounds
- Multiple particle types used
- Effect does not cover character's silhouette
- Duration short (0.2-0.5s) for fast games
- Hitstop compatible

## Anti-Patterns
- Single static sprite for all hits
- Effect offset from hit location
- Overly long duration
- No contrast adjustment for bright vs dark stages
