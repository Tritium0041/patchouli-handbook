# Let Players Cheat the System

Category: Design Specifics

## Summary
Players naturally seek exploits for advantage. These 'cheats' often become memorable fun. Tolerate small exploits that add emergent gameplay.

## Use When
- Balancing difficulty and player agency.

## Do This
1. Identify potential exploits that don't break core progression. Allow repeated retries as strategy. Avoid over-polishing removing all emergent strategies.

## Checklist
- Harmless exploits adding flavor?
- Players can gain advantage through skill/knowledge?
- Do exploits risk trivializing major challenges?
- Considered fun of finding loopholes?

## Anti-Patterns
- Eliminating all possible exploits resulting sterile gameplay
- Allowing game-breaking bugs
