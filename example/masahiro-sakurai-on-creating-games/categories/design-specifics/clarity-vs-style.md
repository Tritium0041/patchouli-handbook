# Clarity vs. Style in UI

Category: Design Specifics

## Summary
UI needs balance between clarity and style depending on game content.

## Use When
- Designing game interfaces.

## Do This
1. Use gaze guidance, hierarchical contrast, window grouping, brightness adjustment, and font choices.

## Checklist
- UI prioritizes gaze guidance?
- Information hierarchy clear?
- Windows group related elements?
- Font and brightness match game style?

## Anti-Patterns
- Only styling ignoring readability
- Only clarity losing personality
