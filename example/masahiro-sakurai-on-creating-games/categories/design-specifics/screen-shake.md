# Screen Shake

Category: Design Specifics

## Summary
Screen shake powerfully conveys impact. Tune with camera movement (3D) or post-render move (2D), apply decay and randomness.

## Use When
- Adding hit impact, explosions, or dramatic events.

## Do This
1. Choose method based on game type. Design multiple shake patterns. Add random variation and fade-out.

## Checklist
- Select shake implementation (camera or post-render)
- Account for UI shaking and black borders
- Create patterns with varying intensity and duration
- Adjust magnitude based on camera FOV
- Add randomness
- Test on different screen sizes

## Anti-Patterns
- Overly long or strong shake causing disorientation
- No shake making impacts weak
- Uniform shake without decay
