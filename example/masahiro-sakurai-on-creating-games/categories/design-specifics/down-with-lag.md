# Down with Lag

Category: Design Specifics

## Summary
Reduce display delay to ensure game experience. Choose low-latency mode and reduce intermediate devices.

## Use When
- Setting up game environment or debugging response speed.

## Do This
1. Enable game mode; direct connection; turn off image enhancement; pay attention to input delay parameters.

## Checklist
- TV game mode on?
- Bypassed extra AV devices?
- Any audio delay?
- Post-processing off?

## Anti-Patterns
- Ignoring delay issues
- Using too many image post-processing
