# Icon Sizing by Importance

Category: UI/UX Design

## Summary
Make icons larger for frequently used functions and smaller for secondary ones, but watch out for text overflow in different languages.

## Use When
- Creating menu or HUD icons.

## Do This
1. Size icons based on frequency of use. Test with the longest word in each language to ensure text doesn't overflow.

## Checklist
- List all menu functions ranked by usage
- Design icon sizes accordingly with padding for text
- Test with all supported languages

## Anti-Patterns
- Making all icons the same size
- Ignoring text length when determining button size
