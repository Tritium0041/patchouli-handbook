# Menu Color Coding

Category: UI/UX Design

## Summary
Use distinct color schemes for different menu sections to aid navigation, but limit colors per screen to avoid chaos.

## Use When
- Designing multi-section menus.

## Do This
1. Assign a dominant color to each major category. Carry that color through submenus. Keep colors per screen to 2-3 plus neutrals.

## Checklist
- Map out menu categories and assign theme colors
- Ensure colors contrast against background
- Test for colorblind accessibility

## Anti-Patterns
- Using rainbow of colors that confuse
- Relying solely on color to convey meaning
