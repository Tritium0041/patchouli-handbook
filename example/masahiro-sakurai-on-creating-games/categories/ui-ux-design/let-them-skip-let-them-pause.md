# Let Them Skip, Let Them Pause

Category: UI/UX Design

## Summary
All non-interactive sequences must be skippable and pausable. Modern players expect control over their time.

## Use When
- Implementing any cinematic or sequence.

## Do This
1. Add skip button for all logos, openings, and cutscenes. Enable pause during any video or animation. Implement line-by-line skip in dialogue.

## Checklist
- All non-interactive moments have skip option
- Pause works during cutscenes
- Logos can be skipped
- Dialogue can be advanced per line

## Anti-Patterns
- Forcing players to watch unskippable logos
- Only providing skip but not pause
- Making skip hard to find
