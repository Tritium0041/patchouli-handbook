# Maps Are Game Screens, Too

Category: UI/UX Design

## Summary
Warns that players often stare at maps instead of the main screen. Use transparent maps, enhance main screen with directional cues, and use environmental landmarks.

## Use When
- Designing game screens with minimaps.

## Do This
1. Use semi-transparent overlays so players can see the game world while checking the map. Add visual indicators on the main screen.

## Checklist
- Minimize need for full-screen map interruptions
- Provide at-a-glance info without obscuring gameplay
- Test where players' eyes naturally go

## Anti-Patterns
- Opaque, full-screen maps that break immersion
- Complex 3D maps hard to read on 2D screens
