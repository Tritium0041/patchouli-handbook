# Text Rendering & Localization

Category: UI/UX Design

## Summary
Consider language-specific text sizes and allow localizers to adjust text animation parameters for better emotional impact across cultures.

## Use When
- Implementing in-game text and localizing the game.

## Do This
1. Use dynamic font sizing. Provide a script parameter system that lets localizers change font size, color, bounce, etc.

## Checklist
- Design UI with flexible layouts
- Create text animation script with parameters
- Test with all target languages

## Anti-Patterns
- Hard-coding text animations
- Not testing with actual translated text
- Assuming all languages take same space
