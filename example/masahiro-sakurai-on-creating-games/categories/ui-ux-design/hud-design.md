# HUD Design

Category: UI/UX Design

## Summary
Design HUD elements that inform without distracting; consider dynamic visibility and thematic integration.

## Use When
- Designing on-screen gameplay indicators.

## Do This
1. Show important info constantly; hide secondary info until needed. Use semi-transparency and animation to reduce clutter.

## Checklist
- List necessary HUD elements and prioritize
- Decide always visible vs context-sensitive
- Implement fade-in/fade-out
- Test in high-action moments

## Anti-Patterns
- Cluttering the screen with too many static indicators
- Ignoring readability in different brightness levels
