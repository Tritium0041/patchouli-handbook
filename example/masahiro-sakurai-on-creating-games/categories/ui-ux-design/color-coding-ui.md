# Color-Coding Your Game UI

Category: UI/UX Design

## Summary
Use color coding to differentiate UI sections but avoid clutter; colors must suit the game's tone.

## Use When
- Designing menu screens or HUDs.

## Do This
1. Choose a limited color palette that fits the game's art style. Assign consistent meanings to colors. Use icons alongside colors for accessibility.

## Checklist
- Color coding aligns with game's visual theme
- No more than 5 distinct colors per screen
- Color-function mapping is intuitive
- Sufficient contrast
- Colors not sole differentiator

## Anti-Patterns
- Using too many colors causing visual noise
- Colors clashing with game's mood
- Relying only on color without text/symbols
