# Button Responsiveness

Category: UI/UX Design

## Summary
Every button press must yield a reaction—even if trivial—to avoid player confusion. Map confirm to multiple buttons for accessibility.

## Use When
- Designing controls, menus, and cutscene interactions.

## Do This
1. Provide visual or audio feedback for every button. Map confirm to A and L for one-handed play. Show skip prompt during cutscenes.

## Checklist
- Assign basic feedback to each button
- Map confirm to at least two buttons
- During cutscenes, detect any button press and show skip option
- Test all buttons for clear response

## Anti-Patterns
- Buttons with no reaction when pressed
- Only one confirm button
- No feedback during movies or loading screens
