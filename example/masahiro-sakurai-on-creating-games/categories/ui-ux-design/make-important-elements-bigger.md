# Make Important Elements Bigger

Category: UI/UX Design

## Summary
Scale UI icons by importance to intuitively guide users. Larger icons for frequent actions, smaller for rare ones.

## Use When
- Designing menu screens or control layouts.

## Do This
1. Size icons based on usage frequency; ensure visual hierarchy supports primary functions.

## Checklist
- List all UI elements by importance
- Assign relative sizes
- Test with directional input if applicable
- Consider localization space constraints

## Anti-Patterns
- Uniform size ignoring usage patterns
- Oversizing non-critical elements
