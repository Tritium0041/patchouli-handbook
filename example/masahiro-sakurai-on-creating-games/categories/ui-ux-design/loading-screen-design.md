# Loading Screen Design

Category: UI/UX Design

## Summary
Handle loading screens by blending them into gameplay or keeping them informative and brief.

## Use When
- Designing loading sequences.

## Do This
1. If possible, hide loading behind gameplay animations. Otherwise, show a clear progress bar or spinning icon.

## Checklist
- Measure actual load times
- Provide visual feedback that loading is happening
- Avoid requiring player input during loading unless necessary

## Anti-Patterns
- Static image with no progress indicator
- Forcing players to watch long unskippable animation every time
