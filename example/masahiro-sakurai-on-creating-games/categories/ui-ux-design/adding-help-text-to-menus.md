# Adding Help Text to Menus

Category: UI/UX Design

## Summary
Menu items need explanatory text, but avoid using the same words as the item itself. Use simple, jargon-free language.

## Use When
- Writing in-game descriptions for menu options.

## Do This
1. For each menu label, write an explanation using different words. Replace game-jargon with plain language.

## Checklist
- Help text wording differs from menu label
- No technical jargon
- Language simple and universal
- User-tested

## Anti-Patterns
- Copying menu item name as help text
- Using terms only core gamers understand
