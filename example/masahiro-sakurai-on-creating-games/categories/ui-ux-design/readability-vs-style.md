# Readability vs Style

Category: UI/UX Design

## Summary
Balance user-friendly clarity with stylish visuals, but never sacrifice readability for the sake of aesthetics.

## Use When
- Designing any game UI.

## Do This
1. Start with a functional layout, then apply style. Test with users unfamiliar with the game. If they struggle, simplify.

## Checklist
- Ensure text is easily readable
- Test UI with various screen sizes
- Get feedback from non-developer testers

## Anti-Patterns
- Making UI too artistic that players miss important information
- Using tiny fonts for style
