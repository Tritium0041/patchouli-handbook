# Menus Define Your World

Category: UI/UX Design

## Summary
UI and font choices dramatically change a game's target audience and world feel. Ensure readability and holistic design.

## Use When
- Choosing art style for UI.

## Do This
1. Select fonts and UI styles that match the intended audience. Ensure all UI elements feel cohesive. Prioritize readability.

## Checklist
- Does font support target language?
- Are UI colors consistent with game world?
- Can players quickly understand menus?
- Design scalable for different screen sizes

## Anti-Patterns
- Overly ornate fonts hindering readability
- Mismatched UI and game art styles
- Ignoring cultural differences in font and color meanings
