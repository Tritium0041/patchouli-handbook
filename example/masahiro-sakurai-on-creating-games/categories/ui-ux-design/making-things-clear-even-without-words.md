# Making Things Clear, Even Without Words

Category: UI/UX Design

## Summary
Use icons, character graphics, and default actions so players can understand and play even without knowing the language.

## Use When
- Designing menus or tutorials for global audience.

## Do This
1. Replace text with meaningful icons/graphics. Provide a 'button mash' shortcut to start the main game immediately.

## Checklist
- Icons self-explanatory across cultures
- Default button-mash leads to core gameplay
- No reliance on reading comprehension

## Anti-Patterns
- Using words as the only explanation
- Forcing players through language-dependent menus before gameplay
