# Button Settings and Key Configuration

Category: UI/UX Design

## Summary
Provide button remapping even in simple games. Use a graphical controller UI; allow duplicate bindings; save configurations per player.

## Use When
- Developing any game that uses controller or keyboard input.

## Do This
1. Implement a config menu with visual controller representation. Allow duplicate assignments. Support multiple profiles.

## Checklist
- Include button remapping from start
- Visual controller representation beats lists
- Allow duplicate assignments
- Save config to player name or controller

## Anti-Patterns
- No remapping option
- Complex menu requiring swap-based editing
- Ignoring platform-default button placements
