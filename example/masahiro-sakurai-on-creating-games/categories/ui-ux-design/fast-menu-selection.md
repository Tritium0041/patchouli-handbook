# Fast Menu Selection

Category: UI/UX Design

## Summary
Proposes adding a scroll wheel to game controllers for rapid menu navigation. The principle of fast, satisfying input persists.

## Use When
- Designing UI navigation in games with many menu options.

## Do This
1. Evaluate if a dedicated scrolling device can accelerate selection; ensure tactile feedback for precision.

## Checklist
- Identify high-frequency menu actions
- Prototype scroll wheel
- Test selection speed vs analog stick
- Incorporate clicky detents for feedback

## Anti-Patterns
- Relying solely on analog stick for long lists without acceleration
- Ignoring input latency
