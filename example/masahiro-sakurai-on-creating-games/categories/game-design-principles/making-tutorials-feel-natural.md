# Making Tutorials Feel Natural

Category: Game Design Principles

## Summary
Tutorials should be integrated into gameplay, not separate training. Use visual cues but ensure they cover all key configurations.

## Use When
- Designing initial player experience.

## Do This
1. Let players learn by playing; provide concise text and small video demonstrations; limit tutorial areas to force skill use.

## Checklist
- Design a real playable first level
- Test if tutorial feels like homework
- Accommodate key configurations

## Anti-Patterns
- Long, detached tutorial levels
- Overwhelming text
- Not updating tutorials for customizable controls
