# More Game Essence Means Less Broad Appeal

Category: Game Design Principles

## Summary
High risk-reward design increases game essence but decreases broad appeal. Examples from Mario and Kirby illustrate this trade-off.

## Use When
- Balancing difficulty for core vs. casual audiences.

## Do This
1. Identify target audience, analyze mechanics risk, adjust difficulty via risk reduction (e.g., health, forgiveness).

## Checklist
- Define primary audience
- Map risk-reward ratio
- Adjust risk factors
- Playtest with both segments

## Anti-Patterns
- Assuming high game essence always equals quality
- Neglecting low-risk options for beginners
