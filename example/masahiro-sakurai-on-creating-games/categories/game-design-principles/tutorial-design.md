# Teach by Doing

Category: Game Design Principles

## Summary
Design tutorials that let players learn through natural gameplay rather than separate practice levels.

## Use When
- Designing introductory sections.

## Do This
1. Integrate gameplay instructions into the first level. Let players perform actions to learn them, avoiding text-heavy explanations.

## Checklist
- Identify core mechanics
- Create low-risk environment
- Present challenges requiring the mechanic
- Gradually increase complexity
- Provide contextual hints without pausing

## Anti-Patterns
- Separate training levels
- Overly long instruction sequences
- Punishing mistakes too harshly during learning
