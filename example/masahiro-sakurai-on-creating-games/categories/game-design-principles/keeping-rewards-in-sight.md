# Keeping Rewards in Sight

Category: Game Design Principles

## Summary
Display progress toward rewards to motivate players; use scarce high-impact items that encourage saving.

## Use When
- Designing progression systems or shop mechanics.

## Do This
1. Show numerical progress. Design shops with few expensive items that give big power boosts. Make goals tangible.

## Checklist
- Implemented visible progress indicator
- Created high-value scarce rewards
- Player can see next goal

## Anti-Patterns
- Hiding progress
- Shops with many cheap incremental items that dilute excitement
