# Consider Rewards First

Category: Game Design Principles

## Summary
Rewards are the primary driver of player motivation. Design the reward system early, including numerical, collectible, and unlockable rewards.

## Use When
- Designing player progression or incentive systems.

## Do This
1. Define reward types early. Ensure each reward has a corresponding use. Make collection feel rewarding.

## Checklist
- Identify core reward types
- Design consumption systems
- Ensure varied and interesting acquisition
- Test reward meaningfulness

## Anti-Patterns
- Adding rewards without purpose
- Too repetitive collection without payoff
