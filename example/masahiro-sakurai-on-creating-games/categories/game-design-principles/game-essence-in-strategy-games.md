# Game Essence in Strategy Games

Category: Game Design Principles

## Summary
Strategy games use rock-paper-scissors style counters, cost differences, and positional elements to create meaningful decisions.

## Use When
- Designing unit balance or maps in a strategy game.

## Do This
1. Define clear counter chains. Differentiate units by cost and stats. Use positioning and range to create asymmetric opportunities.

## Checklist
- Clear counter relationships exist
- Cost matches effectiveness
- Positional advantages matter
- Randomness controlled

## Anti-Patterns
- All units have same cost/strength
- No clear counters
- Too much randomness deciding outcome
