# Long Ago, Numbers Were Used to Draw Pixel Art

Category: Programming & Tech

## Summary
In early microcomputers, pixel art was created by manually entering hexadecimal numbers representing 4x1 pixel patterns.

## Use When
- Understanding retro game development.

## Do This
1. Learn hexadecimal notation: each hex digit = 4 pixels. For color, use separate bitmaps per color plane.

## Checklist
- Hexadecimal pixel editing understood
- Ability to compose 8x8 sprites from hex
- Awareness of color plane layering
- Appreciation for craft

## Anti-Patterns
- Thinking modern tools make pixel art easy
- Dismissing retro techniques as irrelevant
