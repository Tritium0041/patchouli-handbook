# Organize Content with Numbering

Category: Programming & Tech

## Summary
Use systematic file naming and folder structures to manage large volumes of assets.

## Use When
- Managing video, image, or document assets.

## Do This
1. Create numbering scheme for all assets (episode number, scene number). Store in hierarchical folder structure.

## Checklist
- Define consistent naming convention
- Use numbered folders for categories
- Store metadata in spreadsheet
- Back up regularly

## Anti-Patterns
- Ad hoc file names without pattern
- All files in one folder
- Relying on memory to find assets
