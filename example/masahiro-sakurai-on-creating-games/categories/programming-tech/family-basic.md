# Family BASIC

Category: Programming & Tech

## Summary
Explores Famicom's Family BASIC peripheral, a programming environment with 2KB memory, preloaded sprites, battery backup. Author credits it for launching his career.

## Use When
- Learning game programming from scratch or teaching concepts.

## Do This
1. Use simple commands like MOVE, SPRITE. Leverage preset sprites. Implement physics and animation with few lines.

## Checklist
- Understand memory constraints (2KB)
- Master basic movement commands
- Experiment with sprite attributes
- Try creating simple interactive scene

## Anti-Patterns
- Trying complex games without understanding fundamentals
- Ignoring limitations
