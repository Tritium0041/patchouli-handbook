# Online Updates

Category: Programming & Tech

## Summary
Modern games are complex; bugs and balance issues are inevitable. Online updates are necessary but should not crutch—first impressions matter.

## Use When
- Deciding launch quality and post-release update strategy.

## Do This
1. Test as thoroughly as possible before launch. Prioritize launch-day stability. Use updates to polish, not fix critical issues.

## Checklist
- Sufficient internal testing before launch
- Launch version as polished as possible
- Update plan ready but not over-relied upon
- First impression handled

## Anti-Patterns
- Shipping broken game relying on day-one patch
- Frequent updates changing core mechanics
- Ignoring early unpatched player feedback
