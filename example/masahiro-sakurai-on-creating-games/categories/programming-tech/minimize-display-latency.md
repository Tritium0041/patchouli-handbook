# Minimize Display Latency

Category: Programming & Tech

## Summary
Ensure your game responds instantly; help players reduce display lag through settings.

## Use When
- During development and when advising players on setup.

## Do This
1. Optimize input handling. Include options to reduce visual latency (game mode, low latency mode). Test with common displays.

## Checklist
- Measure input-to-action latency internally
- Provide graphics options minimizing lag
- Educate players about display settings
- Avoid unnecessary frame buffering

## Anti-Patterns
- Ignoring latency issues
- Adding framerate caps that increase lag
- Not providing latency-related options
