# Unexpected Results

Category: Programming & Tech

## Summary
Optimization can alter game balance. Online updates help, but offline testing is crucial.

## Use When
- After performance optimizations or porting.

## Do This
1. Re-balance after optimization; test on target hardware; plan for post-launch adjustments.

## Checklist
- Re-test difficulty curve after optimizations
- Compare dev kit vs. retail performance
- Prepare online update capability

## Anti-Patterns
- Assuming performance tweaks don't affect gameplay
- Neglecting hardware differences
