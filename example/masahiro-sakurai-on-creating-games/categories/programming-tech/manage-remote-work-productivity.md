# Manage Remote Work Productivity

Category: Programming & Tech

## Summary
Remote development can reduce efficiency; mitigate with proper equipment and processes.

## Use When
- Transitioning to or operating in remote team setting.

## Do This
1. Provide standard equipment (monitors, chairs, internet upgrades), use collaboration tools, maintain regular communication.

## Checklist
- Equip remote workers with necessary hardware
- Set up VPN and reliable network
- Use project management and communication tools
- Schedule regular check-ins
- Prepare for ~30% drop in efficiency

## Anti-Patterns
- Assuming same productivity as in-office
- Neglecting ergonomics
- Relying solely on email
