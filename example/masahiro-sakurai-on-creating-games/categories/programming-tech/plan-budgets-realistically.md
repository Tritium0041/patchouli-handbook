# Plan Budgets Realistically

Category: Programming & Tech

## Summary
Be aware of all costs: development, marketing, localization, and hidden expenses.

## Use When
- At start of a project.

## Do This
1. Create detailed budget including salaries, software licenses, outsourcing, marketing, contingency. Regularly track expenses.

## Checklist
- List all potential cost categories
- Get quotes from contractors early
- Allocate 10-20% contingency
- Monitor spending monthly

## Anti-Patterns
- Underestimating localization costs
- Ignoring marketing costs
- Not planning for overtime or delays
