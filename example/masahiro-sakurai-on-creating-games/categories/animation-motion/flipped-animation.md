# Flipped Animation

Category: Animation & Motion

## Summary
Mirror character poses and actions so opponents face each other toward the screen, improving visual information and spectacle in fighting games.

## Use When
- Designing 2D or 3D fighting games.

## Do This
1. For 2D sprites, create mirrored versions of all animations. For 3D models, implement a mirror transform. Ensure items mirrored correctly.

## Checklist
- All character animations have mirrored counterparts
- Weapon holding hands swapped correctly
- Mirror applied consistently
- Test with asymmetrical characters

## Anti-Patterns
- Using only rotation without flipping animation
- Leaving items or clothing asymmetrical
