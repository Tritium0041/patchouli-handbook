# Too Much is Just Right

Category: Animation & Motion

## Summary
For action animations, exaggerated motion that risks breaking the model is actually better; most attack animations are too limited.

## Use When
- Animating combat moves or physical actions.

## Do This
1. Push movements beyond what feels 'correct' to near model failure. Use quick overshoot and slight return for linear motions.

## Checklist
- Check if animation could be more extreme
- Use overshoot-and-return for impact
- Avoid safely poses that kill momentum

## Anti-Patterns
- Stopping at 'good enough' rather than 'over the top'
- Correcting model deformities that add character
- Making animations too smooth and weak
