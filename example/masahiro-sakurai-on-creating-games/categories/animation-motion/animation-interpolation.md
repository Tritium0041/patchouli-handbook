# Animation Interpolation Pitfalls

Category: Animation & Motion

## Summary
Warn against over-relying on automatic interpolation when converting 2D to 3D. Manual keyframe adjustment and reducing intermediate frames produces sharper actions.

## Use When
- Animating characters needing crisp, readable moves.

## Do This
1. Exaggerate keyframe poses, reduce tween frames, elongate anticipation and hit frames. Hand-tune transitions.

## Checklist
- Compare auto-interpolation with manual version
- Keyframe count similar to 2D original
- Use follow-through movement that differs from idle

## Anti-Patterns
- Letting default interpolation create floaty actions
- Adding too many frames for fluidity at cost of impact
