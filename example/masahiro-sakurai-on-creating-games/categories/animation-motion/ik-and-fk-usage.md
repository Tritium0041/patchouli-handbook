# IK and FK Usage

Category: Animation & Motion

## Summary
Use IK for foot placement and end-effector tasks; FK for expressive arcs. Exaggerate joint rotations beyond 180° for impact.

## Use When
- Setting up character rig and animating interactions.

## Do This
1. Apply IK to feet for ground alignment. Use FK for arms and head. Over-rotate joints to add snap and energy.

## Checklist
- Feet stay planted on uneven terrain via IK
- FK animations have natural arcs
- Joint rotation limits deliberately exceeded for dramatic effect

## Anti-Patterns
- Using IK for everything leading to mechanical motion
- Never breaking joint limits resulting in stiff animation
