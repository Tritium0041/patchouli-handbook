# Extreme Keyframes for Sharp Animation

Category: Animation & Motion

## Summary
To keep 2D-style sharpness in 3D, exaggerate key poses beyond what looks natural; reduce intermediate frames to avoid softness.

## Use When
- Transitioning 2D character concepts to 3D.

## Do This
1. Push key poses further (bigger anticipation, stronger recoil). Remove unnecessary in-between frames.

## Checklist
- Key poses significantly different from neutral
- Number of frames between key poses minimal
- Animation retains readability despite exaggeration

## Anti-Patterns
- Auto-interpolation creating smooth but weak motion
- Not exaggerating enough resulting in bland animation
