# G: Animation 1 (Category Compilation)

Category: Animation & Motion

## Summary
Comprehensive animation workflow: start with text-based move list, use action figures for reference photos, break moves into four stages, exaggerate poses, use cancel frames.

## Use When
- Starting animation for a new character, especially combat moves.

## Do This
1. Write a move list first; take 70-80 reference photos; design each move with distinct stages; exaggerate weight deformation; set cancel frames; ensure hit pose silhouette clear.

## Checklist
- Text move list with timings and hit frames
- Reference photos from multiple angles
- Four-stage breakdown for each attack
- Exaggerate poses
- Hit pose visibility and silhouette
- Cancel frames before follow-through ends

## Anti-Patterns
- Realistic, understated animation
- Symmetrical idle poses
- Ignoring silhouette
- Cancel frames too early or late
