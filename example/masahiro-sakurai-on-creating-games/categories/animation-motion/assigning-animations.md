# Assigning Animations

Category: Animation & Motion

## Summary
Use move lists and action figure photography to specify actions; each character about 70-80 photos.

## Use When
- Early planning of character actions.

## Do This
1. Write detailed move list including duration and attack frames; use action figures to pose; post-process photos as reference.

## Checklist
- Written move list
- Photos for each keyframe
- Photos processed for contrast
- Supervised to ensure quality

## Anti-Patterns
- Jumping text to modeling
- Ignoring figure/model mobility differences
