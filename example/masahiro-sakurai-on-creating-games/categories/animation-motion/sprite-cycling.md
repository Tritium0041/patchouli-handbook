# Sprite Cycling for Wobble

Category: Animation & Motion

## Summary
Cycle a sprite's display position through a predefined pattern to simulate unsteady flight or wobble.

## Use When
- Animating projectiles or floating objects.

## Do This
1. Define a sequence of x,y offsets and cycle through them every few frames.

## Checklist
- Determine number of frames in cycle
- Set offset magnitude
- Apply cycle to sprite's display position

## Anti-Patterns
- Using random offsets instead of loop
- Wobble too large or fast
