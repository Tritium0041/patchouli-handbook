# Game Development Isn't a Game

Category: Work Ethic & Mindset

## Summary
Game development is professional work; even if you don't like it, complete it with player happiness as goal.

## Use When
- Facing uninteresting tasks or projects.

## Do This
1. Treat work as task; find sense of accomplishment; always prioritize player experience.

## Checklist
- Professional attitude toward work?
- Player happiness as ultimate goal?
- Overcoming personal preferences?

## Anti-Patterns
- Only doing projects you like
- Prioritizing personal preferences over player needs
