# Broad Input, Broad Output for Creatives

Category: Work Ethic & Mindset

## Summary
To improve work quality, intentionally broaden input (play games, watch films, read) and output (write, share, speak). Make it a daily habit.

## Use When
- Boosting personal creativity or team innovation.

## Do This
1. Play at least one new game per week. Write daily/weekly log. Share work in progress. Find format that suits you. Reflect on each input.

## Checklist
- Regularly consume new games/media outside comfort zone
- Output at least short writing per week
- Input followed by reflection
- Habit feels sustainable

## Anti-Patterns
- Binge consuming without analysis
- Outputting without new input
- Comparing output quantity to others
- Neglecting rest and variety
