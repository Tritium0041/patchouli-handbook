# The Power of Suggestion

Category: Work Ethic & Mindset

## Summary
Imagine a terrifying object chasing you to trigger flight response; set tight deadlines to boost efficiency. Running away from deadlines works better than chasing goals.

## Use When
- Struggling with motivation or productivity.

## Do This
1. Before task, vividly imagine something dangerous chasing you. Reframe work as escaping deadline. Set firm short deadline.

## Checklist
- Vivid mental image of pursuing threat created
- Task framed as escaping deadline
- Realistic but tight deadline set

## Anti-Patterns
- Using vague goals without urgency
- Allowing too much time leading to procrastination
- Overdoing stress to burnout; use occasionally
