# Never Get Into Fights

Category: Work Ethic & Mindset

## Summary
The game industry is small; burned bridges will come back. Avoid arguments, gossip, and leaving on bad terms.

## Use When
- Experiencing conflict or considering quitting.

## Do This
1. Communicate issues calmly and directly. If workplace toxic, exit gracefully. Maintain professional relationships. Avoid badmouthing.

## Checklist
- Before confrontation: ask if worth reputation cost
- If leaving: handover properly
- Give feedback with specific examples, not personal attacks
- Assume others will hear about behavior

## Anti-Patterns
- Public arguments
- Gossiping about teammates
- Leaving without notice
- Passive-aggressive communication
