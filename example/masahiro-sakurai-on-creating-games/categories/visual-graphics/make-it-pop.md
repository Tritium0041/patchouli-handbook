# Make It Pop: Visual Effects

Category: Visual & Graphics

## Summary
Use color addition for glow but avoid overuse; combine with hard-edged effects and dark elements for contrast.

## Use When
- Designing game effects.

## Do This
1. Prioritize color addition for glow but control amount; add hard-edged effects; mix in dark elements.

## Checklist
- Color addition not excessive causing blur
- Hard-edged effects included
- Dark elements used to contrast brightness
- Opposite elements (curved/straight, light/dark) employed

## Anti-Patterns
- Relying entirely on color addition
- Neglecting hard edges and dark colors
