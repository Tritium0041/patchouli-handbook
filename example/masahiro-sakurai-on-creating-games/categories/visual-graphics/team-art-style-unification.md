# Team Art Style Unification

Category: Visual & Graphics

## Summary
When mixing characters from different franchises, unify via: lowered saturation, consistent texture detail, adjusted body proportions, redesigned details, and uniform expression style.

## Use When
- Integrating characters from multiple sources into a single game.

## Do This
1. Create a reference board. Reduce saturation. Adjust proportions. Redesign small details. Use similar eye shapes.

## Checklist
- Reference board shared with all artists
- Saturation levels consistent
- Texture detail density similar
- Body proportions feel coherent
- Facial expression style unified

## Anti-Patterns
- Preserving original art styles without adjustment causing visual clash
- Oversaturating or over-detailing to compensate
