# Distinguishing Between Major and Minor Elements

Category: Visual & Graphics

## Summary
Allocate graphical resources wisely: prioritize screen center, character detail over background, use LOD, cut unnecessary detail.

## Use When
- Optimizing graphics for performance-limited platforms.

## Do This
1. Identify high-visibility areas. Invest detail there. LOD for distant objects. Evaluate screen coverage of each element.

## Checklist
- Map viewer attention: center and character primary
- Allocate more polygons/textures to high-impact areas
- Use LOD for distant objects
- Remove details rarely noticed

## Anti-Patterns
- Equal detail distribution regardless of visibility
- Overly detailed far-away objects
