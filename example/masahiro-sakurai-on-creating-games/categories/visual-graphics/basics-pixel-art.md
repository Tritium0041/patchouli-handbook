# The Basics of Pixel Art

Category: Visual & Graphics

## Summary
Fundamental pixel art techniques: use odd pixel dimensions for circles, checkerboard dithering for gradients, and add one extra color for highlights.

## Use When
- Creating pixel art with strict color limits.

## Do This
1. Use odd pixel widths to center symmetry on a single pixel midline. Apply dithering to simulate mid-tones. Add a third color for gradients from edges.

## Checklist
- Sprite dimensions: odd numbers for centered symmetry
- Color count: start with 2, then add 1-2 for depth
- Test at actual game resolution

## Anti-Patterns
- Even dimensions forcing off-center alignment
- Over-dithering creating noise
- Too many colors losing retro feel
