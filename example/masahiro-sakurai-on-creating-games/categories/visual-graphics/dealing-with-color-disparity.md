# Dealing With Color Disparity

Category: Visual & Graphics

## Summary
Monitor inconsistencies cause color differences; calibrate tools, use neutral lighting, and rely on a reference display for final approval.

## Use When
- When team monitors show different colors or brightness.

## Do This
1. Calibrate all team monitors to a common standard. Set up a reference monitor for team reviews. Use neutral white lighting.

## Checklist
- All monitors calibrated to same brightness and color temperature
- Color measurement tools used
- Reference monitor available
- Lighting is neutral

## Anti-Patterns
- Assuming same model monitors display identical colors
- Ignoring ambient lighting effects
