# Get the Sense of Scale Right

Category: Visual & Graphics

## Summary
Large objects in games often look like miniatures. Fix this by avoiding repetitive textures, reducing saturated colors, controlling specular highlights, and using normal maps consistent with size.

## Use When
- Modeling or texturing environmental assets.

## Do This
1. Use high-resolution textures that tile naturally. Lower saturation and specular intensity for large objects. Add wear and tear.

## Checklist
- Check texture tiling loops
- Reduce color saturation to match lighting
- Lower specular intensity
- Add small imperfections for realism
- Verify normal map scale matches object size

## Anti-Patterns
- Overusing identical textures on large surfaces
- Ignoring environmental lighting context
