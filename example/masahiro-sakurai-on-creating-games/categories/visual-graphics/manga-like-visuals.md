# Manga-like Visuals

Category: Visual & Graphics

## Summary
Embrace non-realistic techniques: mouths visible sideways, eyes seen through glasses frames, squash-and-stretch from animation. Use shape animation for elastic effects.

## Use When
- Stylizing 3D characters for cartoon/anime look.

## Do This
1. Study manga/anime conventions. Use shape keys or morph targets for squash/stretch. Allow geometry to break realism for clarity.

## Checklist
- Profile mouth offset used for clarity
- Eyes visible through frame edges
- Squash/stretch applied via shape animation
- Unrealistic proportions consciously chosen

## Anti-Patterns
- Sticking to strict realism for all characters
- Avoiding cartoon conventions because they are unrealistic
