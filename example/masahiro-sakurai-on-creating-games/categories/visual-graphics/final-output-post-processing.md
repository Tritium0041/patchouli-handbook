# Final Output Post-Processing

Category: Visual & Graphics

## Summary
On high-end hardware, post-processing is more important than raw polygon count. Frame buffer manipulation defines visual quality.

## Use When
- Optimizing graphics pipeline for modern consoles or PC.

## Do This
1. Invest in post-processing: color grading, ambient occlusion, depth of field, bloom, screen-space reflections. Tune parameters for artistic style.

## Checklist
- Post-processing effects enhance art style without obscuring gameplay
- Frame buffer resolution and format optimized
- Effects are scalable
- Overall image not too dark or overexposed

## Anti-Patterns
- Over-reliance on high polygon counts ignoring post-processing
- Heavy effects causing input lag or frame drops
- Inconsistent visual style due to uncoordinated effects
