# Color Accessibility

Category: Visual & Graphics

## Summary
Ensure game elements are distinguishable for colorblind players by using brightness differences and color blindness simulation filters.

## Use When
- Designing any game that uses color-coded information.

## Do This
1. Use color blindness filters to test all color-coded elements. Increase brightness contrast where colors are confused. Convert to grayscale to check luminance.

## Checklist
- All color-coded elements have sufficient brightness difference
- Player can distinguish elements without relying solely on hue
- Grayscale test shows clearly separated objects
- UI icons include shape or pattern cues

## Anti-Patterns
- Using only red/green distinction without brightness difference
- Assuming all players see colors normally
