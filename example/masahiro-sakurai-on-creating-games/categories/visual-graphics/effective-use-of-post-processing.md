# Effective Use of Post-Processing

Category: Visual & Graphics

## Summary
Modern hardware allows frame buffer and shader effects that dramatically improve visual quality. Use subtly to unify art style.

## Use When
- Implementing final graphics pipeline.

## Do This
1. Use post-processing to unify the art style. Add subtle effects like bloom or motion blur that enhance feel. Be careful not to overdo it.

## Checklist
- Choose consistent color grading
- Implement anti-aliasing
- Add depth of field for cinematic focus
- Test performance impact and optimize shaders

## Anti-Patterns
- Applying heavy blur that ruins readability
- Using expensive shaders that tank framerate
- Ignoring HDR calibration
