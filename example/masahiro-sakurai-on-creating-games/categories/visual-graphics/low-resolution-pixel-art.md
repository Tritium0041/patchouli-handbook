# Low-Resolution Pixel Art Techniques

Category: Visual & Graphics

## Summary
For small sprites, use odd pixel widths to get a center line for smoother curves. Use highlight/edge manipulation for material feel.

## Use When
- Creating pixel art in low resolution or retro-style games.

## Do This
1. Draw circles with odd dimensions to align centers. Adjust highlights and edges to simulate different materials.

## Checklist
- Circles use odd pixel dimensions
- Material type reflected in highlight and edge treatment
- Sprite reads well at intended display size

## Anti-Patterns
- Forcing even dimensions resulting in jagged curves
- Uniform highlights ignoring material differences
