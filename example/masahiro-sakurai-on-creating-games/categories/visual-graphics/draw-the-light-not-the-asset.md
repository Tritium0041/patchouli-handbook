# Draw the Light, Not the Asset

Category: Visual & Graphics

## Summary
Graphic drawing should represent reflected light using color variations, spray gradients, and atmospheric perspective.

## Use When
- Creating game assets.

## Do This
1. Think about light direction and color; use spray or gradient to simulate lighting; add hue variation; simulate air perspective.

## Checklist
- Consider light source
- Use color overlay or spray for shading
- Add hue variation
- Add sense of atmosphere

## Anti-Patterns
- Drawing material without considering light
- Overly complex methods
