# A Fight Between Live Action and Animation

Category: Visual & Graphics

## Summary
Five techniques to unify cartoon and realistic characters: desaturation, balanced texture, proportion adjustment, re-design, realistic motions.

## Use When
- Integrating characters from different art styles.

## Do This
1. Apply each technique iteratively to create a cohesive visual language.

## Checklist
- Reduce saturation of bright characters
- Add subtle texture to cartoon characters, reduce detail on realistic ones
- Adjust head-to-body ratio
- Redesign costume elements to fit world consistency
- Replace cartoonish expressions with realistic physics

## Anti-Patterns
- Leaving characters in original style without adjustment
- Over-smoothing that loses character identity
