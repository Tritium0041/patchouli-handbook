# Super Smash Bros. Melee

Category: Game Concepts & Case Studies

## Summary
Development concept: massively power-up original Smash (graphics, audio, content). Used GameCube disk for streaming music, CG cutscenes, figure collection.

## Use When
- Learning about sequel design or ambitious project scope.

## Do This
1. Identify and improve every aspect from original; embrace new hardware; include unique extra content.

## Checklist
- Target clear 'power-up' goal for sequel
- Leverage new hardware capabilities fully
- Add non-essential content to delight players
- Coordinating external collaborations

## Anti-Patterns
- Incremental upgrade without significant leaps
- Ignoring new platform's potential
- No bonus content
