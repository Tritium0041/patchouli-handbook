# Game & Watch Design Preservation

Category: Game Concepts & Case Studies

## Summary
Showcasing original LCD patterns from Game & Watch used as reference in Smash. Emphasizes preserving historical game assets.

## Use When
- Needing authentic retro elements in modern game.

## Do This
1. Secure permission to use original assets; study constraints-driven design of old LCD games.

## Checklist
- Research original game hardware
- Acquire official assets if possible
- Adapt pixel art/layout to modern resolution

## Anti-Patterns
- Ignoring original context
- Over-modernizing look
