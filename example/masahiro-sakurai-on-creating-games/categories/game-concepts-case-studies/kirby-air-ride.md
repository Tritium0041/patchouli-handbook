# Kirby Air Ride: Development Case Study

Category: Game Concepts & Case Studies

## Summary
A case study on creating with limited time. Core mechanic: drift plus charge-and-release (risk/reward). Focus on variety (City Trial) rather than speedrunning. Vehicles differ only by parameters set by Sakurai.

## Use When
- Considering a spin-off with constrained resources.

## Do This
1. Identify core mechanic (drift+charge) offering risk/reward. Expand variety rather than optimize for time. Use parameter-only differentiation for multiple vehicles.

## Checklist
- Core mechanic simple but satisfying?
- Variety in modes/objectives?
- Visual distinction without underlying complexity?
- Achievement system to track progress?

## Anti-Patterns
- Overcomplicating when time limited
- Vehicles fundamentally different handling increasing imbalance
