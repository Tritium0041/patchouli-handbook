# Super Smash Bros. for 3DS / Wii U

Category: Game Concepts & Case Studies

## Summary
Dual-platform development with shared systems, unique features per console, technical achievements (60fps + 3D).

## Use When
- Planning multi-platform game with cross-features.

## Do This
1. Leverage each platform's unique strengths; coordinate with external studios.

## Checklist
- Define platform-specific features
- Ensure core gameplay parity where possible
- Plan DLC and update infrastructure
- Test performance on each target hardware

## Anti-Patterns
- Treating platforms as identical ports
- Ignoring hardware limitations
