# Meteos: Innovation in Puzzle Design

Category: Game Concepts & Case Studies

## Summary
Core innovation flips traditional block-puzzle mechanics: launch blocks upward as propulsion. Each planet has unique shapes, physics, audio.

## Use When
- Brainstorming new mechanic or originality in familiar genre.

## Do This
1. Identify fundamental assumption (e.g., 'eliminate to survive') and invert it. Experiment with varied rules per level.

## Checklist
- List core assumptions
- Invert one and prototype
- Multiple levels with distinct rule variations
- Test for fun and uniqueness

## Anti-Patterns
- Sticking to genre conventions
- Neglecting performance optimization
