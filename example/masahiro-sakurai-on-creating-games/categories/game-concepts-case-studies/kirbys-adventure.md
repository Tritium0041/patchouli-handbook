# Kirby's Adventure: Introducing Copy Abilities

Category: Game Concepts & Case Studies

## Summary
Copy abilities allow beginners to clear easily and experts to explore deeply, enriching character identity.

## Use When
- Designing core mechanics for different player levels.

## Do This
1. Create shallow and deep mechanics; balance for newbies and experts; adjust parameters for imbalance.

## Checklist
- Easy clear path provided?
- Depth for experts?
- Mechanic enhances character appeal?

## Anti-Patterns
- Serving only one player group
- Copy abilities too complex or useless
