# Super Smash Bros.

Category: Game Concepts & Case Studies

## Summary
Origin of Smash Bros: simplified controls, damage accumulation, using iconic characters to reduce entry barrier.

## Use When
- Designing fighting game or looking for control simplicity innovations.

## Do This
1. Prioritize intuitive controls (direction+button). Implement damage accumulation changing knockback. Use recognizable characters.

## Checklist
- Simplified input scheme
- Dynamic knockback based on damage
- Chosen characters attracting broad audience

## Anti-Patterns
- Requiring execution-heavy combos
- Complex directional inputs
- Using obscure characters
