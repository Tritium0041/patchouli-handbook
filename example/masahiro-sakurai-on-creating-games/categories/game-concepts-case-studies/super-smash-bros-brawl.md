# Super Smash Bros. Brawl

Category: Game Concepts & Case Studies

## Summary
Development insights: online play, single-player mode 'Subspace Emissary', new systems like Final Smash and Assist Trophies, slower pace for casuals, professional test players.

## Use When
- Conceptualizing large-scale sequels.

## Do This
1. Balance online competitive features with offline social play. Create substantial single-player content. Use signature moves to enhance identity.

## Checklist
- Online mode preserves core fun?
- Single-player substantial?
- New mechanics integrated and balanced?
- Difficulty tuned for both casual and hardcore?

## Anti-Patterns
- Online diminishing local multiplayer
- Single-player tacked on
- Too fast or complex for intended audience
