# Canceled Games

Category: Team Management & Workflow

## Summary
Project cancellation happens. Developers should be aware of business pressures and contribute beyond assigned tasks to help project succeed.

## Use When
- Working on a game in development.

## Do This
1. Stay informed about project health. Proactively communicate issues. Take ownership of overall success. Support teammates.

## Checklist
- Understand why projects get cancelled
- Regular check-ins on project status
- Willingness to adapt and contribute outside specialization

## Anti-Patterns
- Only caring about own tasks
- Siloed work
- Assuming someone else will solve problems
