# Stay True to Your Concept

Category: Team Management & Workflow

## Summary
The original concept is a beacon. Long development can blur focus, but never abandon core vision. Changing direction mid-dev wastes resources.

## Use When
- Feeling tempted to pivot or when team asks for scope changes.

## Do This
1. Write concept in one sentence and display it visibly. Revisit in every milestone. If must change, evaluate cost and morale.

## Checklist
- Is current development aligned with original concept?
- Are proposed changes improving or diluting core?
- Concept communicated clearly to team?

## Anti-Patterns
- Chasing trends and losing unique identity
- Making changes based on single playtester
- Allowing game to become jack of all trades
