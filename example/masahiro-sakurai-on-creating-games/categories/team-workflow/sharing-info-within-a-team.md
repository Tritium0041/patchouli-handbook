# Sharing Info Within a Team

Category: Team Management & Workflow

## Summary
Three methods: daily dev log (with comments), daily screenshot, periodic project showcase presentations.

## Use When
- Improving communication in a team.

## Do This
1. Maintain daily dev log, post one screenshot each day, hold regular showcase events.

## Checklist
- Create shared dev log updated daily
- Post one in-progress screenshot daily
- Schedule project showcases every few months
- Encourage cross-discipline attendance

## Anti-Patterns
- Silent development
- Information silos
- Only top-down communication
