# Supervision Workflow

Category: Team Management & Workflow

## Summary
Handle supervision requests via email processed in order of arrival, replying same day. Set aside 'no supervision' periods for focused work.

## Use When
- Setting up review process.

## Do This
1. Use email for submissions. Process in FIFO order. Aim for same-day response. Communicate 'supervision hours'.

## Checklist
- All submissions acknowledged within 24 hours
- Clear priority system
- Designated times when supervision not available

## Anti-Patterns
- Letting emails pile up unread
- Interrupting deep work for every single request
