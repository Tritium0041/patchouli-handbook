# Jobs in Game Development

Category: Team Management & Workflow

## Summary
Overview of typical roles: Director, Planner, Programmer, Model Artist, Artwork, Motion, Effect, Sound, UI, Technical Supporter, Manager, Monitor, Debugger.

## Use When
- Building a team or understanding team dynamics.

## Do This
1. Clearly define each role's responsibilities. Foster cross-discipline communication. Regularly review progress.

## Checklist
- Roles clearly defined
- Team members understand each other's work
- Process for handovers
- Conflicts resolved constructively

## Anti-Patterns
- Assuming everyone knows what others do
- Lack of documentation
