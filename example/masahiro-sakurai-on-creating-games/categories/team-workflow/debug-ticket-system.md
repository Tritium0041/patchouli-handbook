# Debug Ticket System

Category: Team Management & Workflow

## Summary
Manage bugs with ticket system: severity ranking (S/A/B/C), assign to developers, verify fix, archive. Use unified ROM version for testing.

## Use When
- Organizing debug and QA.

## Do This
1. Create tickets for each bug. Rank severity. Assign. After fix, retest and close. Keep single 'golden' build.

## Checklist
- All bugs logged with repro steps and severity
- Fixed bugs verified in multiple combinations
- Ticket status tracked

## Anti-Patterns
- No severity ranking
- Multiple different ROM versions in use
