# Make the Tempo Match the Game

Category: Audio Design

## Summary
Music tempo should align with gameplay intensity; e.g., 130-170 BPM for battles, slower for exploration.

## Use When
- Composing or selecting background music.

## Do This
1. Determine core gameplay speed. Choose BPM that matches. Consider dynamic tempo changes.

## Checklist
- Identified BPM for main gameplay
- Tested music with gameplay pace
- Considered adaptive tempo system

## Anti-Patterns
- Using same tempo for all scenes
- Music tempo too slow for fast action or vice versa
