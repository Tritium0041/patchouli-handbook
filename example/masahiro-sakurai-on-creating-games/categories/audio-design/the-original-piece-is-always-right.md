# The Original Piece is Always Right

Category: Audio Design

## Summary
When remixing game music, respect the original as heard by players, even if it defies music theory.

## Use When
- Arranging or covering classic game soundtracks.

## Do This
1. Preserve memorable motifs, timing, and lyrics. Test with fans.

## Checklist
- Identify the 'true' melody as perceived by players
- Retain signature sections and tempo changes
- Prepare multiple versions for different regions if needed

## Anti-Patterns
- Over-correcting based on theoretical correctness
- Ignoring nostalgic attachment
