# Reference Music Cautions

Category: Audio Design

## Summary
When using existing music as reference, avoid being overly constrained by it; allow composers creative freedom.

## Use When
- Commissioning music or selecting temp tracks.

## Do This
1. Provide references for mood and style, but explicitly encourage divergence and original ideas.

## Checklist
- Reference music used only as starting point, not blueprint
- Composer understands desired emotion, not exact notes
- Final cue distinct from reference

## Anti-Patterns
- Demanding close copy of reference
- Rejecting original ideas that deviate
