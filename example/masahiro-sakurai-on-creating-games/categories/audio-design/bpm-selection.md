# BPM Selection

Category: Audio Design

## Summary
Match music BPM to the desired intensity: fast (130-170) for action, slower for exploration.

## Use When
- Choosing or composing music for a scene.

## Do This
1. For combat or high-tension sections, use BPM 130-170. For menus or calm exploration, BPM 80-120.

## Checklist
- Identify emotional pace of each scene
- Select music tracks with appropriate BPM
- Test if music matches player's rhythm

## Anti-Patterns
- Using same tempo for all areas
- Ignoring that BPM affects player arousal
