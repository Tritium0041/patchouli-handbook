# Realism vs Exaggeration in SFX

Category: Audio Design

## Summary
Choose sound style based on game's visual tone: exaggerated for arcade/action, realistic for simulation/horror.

## Use When
- Designing sound effects for a game.

## Do This
1. If game has stylized visuals, go for bigger-than-life sounds. If realistic, record actual sounds and process minimally.

## Checklist
- Determine game's art direction (realistic or stylized)
- Create SFX prototypes in both styles; test which feels better
- Consistency: don't mix exaggerated and realistic sounds

## Anti-Patterns
- Using cartoon sounds in photorealistic game
- Vice versa
