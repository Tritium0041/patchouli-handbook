# Audio as Fiction and Non-Fiction

Category: Audio Design

## Summary
Game sound design needs balance between exaggeration and realism. Fighting games benefit from exaggerated sounds, while realistic games need authenticity.

## Use When
- Designing sound effects to match game type.

## Do This
1. For non-realistic games, use exaggerated sounds; for realistic games, use authentic sounds; test player feedback.

## Checklist
- Analyze game style
- Select sound style accordingly
- Test with players

## Anti-Patterns
- Realistic sounds in cartoon games
- Exaggerated sounds in photorealistic games feeling dissonant
