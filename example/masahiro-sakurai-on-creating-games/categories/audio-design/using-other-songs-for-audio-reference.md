# Using Other Songs for Audio Reference

Category: Audio Design

## Summary
Using existing songs as audio references can help but may limit creativity. Allow composers creative freedom.

## Use When
- Commissioning original music or selecting licensed tracks.

## Do This
1. Use reference tracks for direction without being bound. Allow composers creative freedom. If a specific song fits perfectly, consider licensing.

## Checklist
- Choose reference tracks that capture mood, not to copy
- Communicate expectations clearly
- Be open to deviations
- Licensing if appropriate

## Anti-Patterns
- Over-attachment to a single reference
- Forcing composer to imitate exactly
